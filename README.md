# Plan Checker

Я сделала эту программу, чтобы не проверять планы работ предприятий вручную. Она читает планы за несколько периодов, сравнивает задачи и сохраняет результаты в текстовый отчёт.

## Что она умеет

- Показывает предприятия без задач в последнем плане.
- Отдельно показывает тех, кто написал «нет», прочерк или «н/д».
- Ищет одинаковые задачи у одного предприятия в трёх и более последовательных периодах.
- Ищет проекты из справочника в последнем плане. В отчёт попадают проекты с тремя и более упоминаниями в разных записях задач.

## Как запустить

Нужен Python 3.

Открываем терминал в папке проекта и выполняем:

```bash
python main.py
```

Отчёт сохранится в `reports/repeats.txt`.

## Какие файлы нужны

- `enterprises.txt` — список предприятий.
- `data/` — планы работ в формате CSV.
- `projects.txt` — названия проектов и варианты поиска.

Файлы планов называются по датам периода:

```text
2026-10-05_2026-10-18.csv
```

В справочнике проектов одна строка выглядит так:

```text
Чона газ;чона газ|чоны газ|чоне газ|чону газ
```

## Особенности

- Заполнение и проекты проверяются только по последнему плану.
- Для поиска повторов нужны предыдущие планы без разрывов между периодами.
- При сравнении не учитываются регистр, различие «ё/е» и лишние пробелы.
- Одна ячейка с задачей считается одной записью, даже если внутри несколько пунктов.
